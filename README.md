# 객주 장터지기

거상에서 원하는 거래 소식을 Windows 알림으로 받아보세요. 로그인 없이 사용할 수 있습니다.

## 설치

[최신 설치 파일 받기](https://github.com/gaekjuju/gaekju-jangteojigi/releases/latest) → **Assets의 x64-setup.exe**를 실행하세요. Windows 11 64비트를 기준으로 제공합니다. Npcap이 없으면 앱의 안내에 따라 설치해 주세요.

## 사용

- **관심 품목:** 품목·별칭 또는 키워드를 검색하고 알림을 등록합니다. 가격을 비우면 가격에 관계없이 알려줍니다.
- **사통팔달:** 품목·내용·작성자로 모인 소식을 찾아봅니다.
- **육의전 Beta:** 이용자가 확인한 검색 결과를 모아 보여줍니다. 모든 매물이 포함되지는 않으며, 이미 판매되거나 내려갔을 수 있습니다.
- **설정:** Windows 시작 시 실행, 자료 제공, 사용법을 확인합니다. 자료 제공에 참여하지 않아도 개인 알림은 사용할 수 있습니다.

앱을 닫거나 최소화하면 트레이로 이동합니다. 트레이 아이콘을 두 번 누르면 다시 열립니다. 새 버전은 앱에서 안내합니다.

## 알아두세요

기존 시험판 사용자는0.1.0 설치 파일로 한 번 전환해 주세요. 이후 업데이트는 이 저장소에서 받습니다. Windows의 **‘PC 보호’ 경고는 아직 나타날 수 있습니다.**

이 저장소는 설치 파일 배포용입니다. 설치하려면 **x64-setup.exe**를 선택하세요. Source code 파일은 프로그램 설치 파일이 아닙니다.
