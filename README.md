## 처음 쓰기

1. 장터지기를 설치하고 객주에 로그인합니다.
2. 거상에서 가방을 열고 품목에 마우스를 올립니다. 이미 게임을 켠 채로 업데이트했다면 캐릭터 선택 화면에 한 번 다녀오세요.
3. 가방에서 **Tab**은 통합 검색, **Shift**는 객주 매물 등록, **Ctrl**은 가방 가격 합계입니다. **F2**는 빠른 메뉴를 엽니다.

13개 서버의 육의전 현재 매물과 시세를 살펴보고, 객주·사통팔달·좌판을 한 번에 검색할 수 있습니다. 조건에 맞는 매물이 나오면 주리가 알려 줍니다. 휴대폰의 객주 앱에서도 같은 계정으로 로그인하고 알림을 켜세요.

객주 매물은 가방이나 앱에서 올릴 수 있습니다. 받은 신청을 수락하고 채팅으로 약속을 잡은 뒤, 물건과 돈은 게임에서 직접 주고받습니다. 장터지기는 게임의 거래나 육의전 등록 버튼을 대신 누르지 않습니다.
